# bolo_doubt_solver
AI-powered doubt-solver that explains student questions in Hindi, Hinglish, or English — with analytics tracking which topics students struggle with most.
Bolo — AI Doubt Solver in Regional Languages

The Problem:
Most AI learning tools explain concepts in polished English, which doesn't match 
how millions of Indian students actually think and learn — in Hindi, Hinglish, 
or their regional language. This creates an accessibility gap where AI's benefits 
don't reach the students who need them most.

Our Solution:
Bolo lets students ask any academic doubt and get it explained in their preferred 
language — Hindi, Hinglish, or English — using simple words and relatable analogies, 
just like a friendly teacher would explain it. Every doubt is automatically tagged 
by subject and topic using AI, powering a built-in analytics dashboard that shows 
which topics and languages students struggle with most.

Why It Matters:
Beyond helping individual students, this data gives teachers and schools visibility 
into where an entire class is struggling — turning a simple chatbot into a tool that 
can improve how subjects are taught, not just how they're explained one-on-one.

Tech Stack:
Python, Streamlit, Groq API (LLM), Pandas for analytics
